linux-labs

Hands-on Linux sysadmin labs for Rocky Linux, RHEL and AlmaLinux 8 and 9, driven by the labctl command.

Install

curl -fsSL https://matej-basic.github.io/linux-labs/install | sudo bash

The script adds the dnf repository, imports the signing key and installs the linux-labs package. Run it again to upgrade.

Manual install

sudo curl -fsSL -o /etc/yum.repos.d/linux-labs.repo https://matej-basic.github.io/linux-labs/linux-labs.repo
sudo rpm --import https://matej-basic.github.io/linux-labs/RPM-GPG-KEY-linux-labs
sudo dnf install linux-labs

First lab

labctl list
sudo labctl start files-01
labctl grade files-01
sudo labctl reset files-01

All labs by category: lab catalog.
