Start a lab. Do the task. Get graded.

55 hands-on labs for Rocky Linux and RHEL 8 and 9, from files and users to SELinux, storage and clustering. One command installs everything.

curl -fsSL https://matej-basic.github.io/linux-labs/install | sudo bash

Rocky Linux, RHEL or AlmaLinux 8 or 9 · a user with sudo · internet access

Install by hand instead

These three commands do the same as the install script: add the dnf repository, import the signing key and install the package.

sudo curl -fsSL -o /etc/yum.repos.d/linux-labs.repo https://matej-basic.github.io/linux-labs/linux-labs.repo
sudo rpm --import https://matej-basic.github.io/linux-labs/RPM-GPG-KEY-linux-labs
sudo dnf install linux-labs
